### Stack técnica que o portfólio apresenta

- **Dados & ML**: Python com pandas e scikit-learn — pipelines, modelagem e avaliação;
- **Análise**: Excel e Power Query com IA no fluxo de trabalho (Copilot, Claude Code, GPT Agents);
- **Interfaces**: React/TypeScript para colocar as análises na mão do usuário;
- **Backend**: Java/Spring Boot (ver kodapay-api e kodabudget-api).

### Direção "Cosmic Engraving"

- Placa fixa (`#plate`) com o vídeo de gravura ASCII gerado por pipeline próprio (repo ascii-anim-gravura) — cobre o viewport inteiro, com leve tilt de mouse (parallax);
- Paleta: preto puro de fundo, superfícies `#0D0F13`/`#12141A`, âmbar `#FFE4A8` como único acento, bordas em `rgba(241,241,238,.10)`;
- Cormorant Garamond para display, Georgia como serif de corpo, Consolas para código;
- `assets/cosmic-bg.js` e `assets/engraving.js` — geradores do fundo, mesma linguagem visual do vídeo.

### Decisões

- Zero framework — HTML/CSS/JS puro, deploy direto no GitHub Pages;
- Favicon e apple-touch-icon dedicados, meta description e Open Graph próprios;
- Uma página só, hierarquia tipográfica clara, sem interações de "AI gimmick".
